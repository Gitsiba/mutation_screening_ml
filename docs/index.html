From variant calls to clear evidence.

Load a plain-text VCF to inspect records, review caller filters, search fields, compare chromosome-level counts, and export the filtered table. Processing happens locally in this browser; selected files are not uploaded.

Research use only. This tool summarizes VCF records; it does not validate somatic status, infer pathogenicity, recommend treatment, or run a trained machine-learning model. RNA-seq variant calls may include expression and alignment artifacts. No patient data should be used in a public demo.
